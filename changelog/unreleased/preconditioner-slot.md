* added: `AMG()` is a preconditioner, `SolverSetup(solver=Cg(), preconditioner=AMG())`, run with `Cg()`, `Bicgstab()` or the new `Richardson()` (repeated V-cycles). The same settings run on every path: `AMG()` maps to PETSc `GAMG()` on distributed meshes and `GAMG()` or `BoomerAMG()` to the native AMG on serial meshes, each with a one-time warning. [#244](@ref)
* changed: With an AMG preconditioner, equations no longer build and refresh an unused second preconditioner. Which preconditioner runs on which solve path is defined in one table, and `NormDiagonal()` maps to PETSc `jacobi` on distributed meshes. [#244](@ref)
* deprecated: `SolverSetup(solver=AMG(mode=...))` warns and runs as `solver=<mode>, preconditioner=AMG(...)`. `AMG(mode=...)` is ignored in favour of `solver`, and `AMGSolver()` is now `Richardson()`. [#244](@ref)
